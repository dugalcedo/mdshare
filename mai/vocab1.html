What is HTML? ¿Qué es HTML?

HTML is the language of web pages. Every web page you visit is made with HTML.

HTML tells the browser what is on the page: titles, paragraphs, pictures, links, lists, and more.

Every box on this page has EN and ES buttons. Click ES to read the box in Spanish.

HTML es el lenguaje de las páginas web. Todas las páginas web que visitas están hechas con HTML.

HTML le dice al navegador qué hay en la página: títulos, párrafos, imágenes, enlaces, listas y más.

Cada caja de esta página tiene botones EN y ES. Haz clic en EN para leer la caja en inglés.

Parts of an element Partes de un elemento

<a href="https://example.com"2>1Click here3</a>4
  1. 1 opening tag · etiqueta de apertura
  2. 2 attribute · atributo
  3. 3 content · contenido
  4. 4 closing tag · etiqueta de cierre

1 + 2 + 3 + 4 = element · elemento

This is one element. It has four parts:

1. The opening tag starts the element.
2. The attribute gives extra information. Here, href says where the link goes.
3. The content is what people see on the page.
4. The closing tag ends the element. It has a slash: /

Esto es un elemento. Tiene cuatro partes:

1. La etiqueta de apertura empieza el elemento.
2. El atributo da información extra. Aquí, href dice a dónde va el enlace.
3. El contenido es lo que la gente ve en la página.
4. La etiqueta de cierre termina el elemento. Tiene una barra: /

Important words Palabras importantes

Tag etiqueta

A tag is a word inside angle brackets: < and >. Tags tell the browser where an element starts and where it ends. Example: <p>

Una etiqueta es una palabra dentro de los signos < y >. Las etiquetas le dicen al navegador dónde empieza y dónde termina un elemento. Ejemplo: <p>

Opening tag etiqueta de apertura

The first tag. It opens (starts) the element. Example: <p>

La primera etiqueta. Abre (empieza) el elemento. Ejemplo: <p>

Closing tag etiqueta de cierre

The last tag. It closes (ends) the element. It looks like the opening tag, but with a slash / before the name. Example: </p>

La última etiqueta. Cierra (termina) el elemento. Es igual a la etiqueta de apertura, pero con una barra / antes del nombre. Ejemplo: </p>

Element elemento

An element is the complete thing: opening tag + content + closing tag. Example: <p>Hello</p> is one paragraph element. A web page is made of many elements.

Un elemento es la cosa completa: etiqueta de apertura + contenido + etiqueta de cierre. Ejemplo: <p>Hello</p> es un elemento de párrafo. Una página web está hecha de muchos elementos.

Content contenido

The content is what is between the opening tag and the closing tag. In <p>Hello</p>, the content is Hello. Content can be text or other elements.

El contenido es lo que está entre la etiqueta de apertura y la etiqueta de cierre. En <p>Hello</p>, el contenido es Hello. El contenido puede ser texto u otros elementos.

Attribute atributo

An attribute gives extra information about an element. It goes inside the opening tag. It has a name and a value: name="value". Example: <a href="https://example.com">

Un atributo da información extra sobre un elemento. Va dentro de la etiqueta de apertura. Tiene un nombre y un valor: nombre="valor". Ejemplo: <a href="https://example.com">

Value valor

The value is the part of an attribute after the equals sign =. Put it inside quotes " ". In alt="A cat", the value is A cat.

El valor es la parte del atributo después del signo igual =. Se escribe entre comillas " ". En alt="A cat", el valor es A cat.

Empty element (void element) elemento vacío

Some elements have no content and no closing tag. They are called empty elements or void elements. Examples: <img>, <br>, <input>

Algunos elementos no tienen contenido ni etiqueta de cierre. Se llaman elementos vacíos. Ejemplos: <img>, <br>, <input>

Nesting anidar / anidamiento

Nesting means putting one element inside another element. Close the inside element first, before you close the outside element.

Anidar significa poner un elemento dentro de otro elemento. Primero cierra el elemento de adentro, antes de cerrar el elemento de afuera.

Parent / Child / Sibling padre / hijo / hermano

<ul> ← parent · padre
<li>Apples</li> ← child · hijo
<li>Bananas</li> ← child · hijo
</ul>

The two <li> elements are siblings · hermanos

When an element is inside another element, the outside one is the parent and the inside one is the child. Here, <ul> is the parent and each <li> is a child.

Elements with the same parent are siblings (like brothers and sisters). The two <li> elements are siblings.

Cuando un elemento está dentro de otro, el de afuera es el padre y el de adentro es el hijo. Aquí, <ul> es el padre y cada <li> es un hijo.

Los elementos que tienen el mismo padre son hermanos. Los dos <li> son hermanos.

Angle brackets signos de menor y mayor que

The symbols < and >. Every tag starts with < and ends with >.

Los símbolos < y > (también se llaman corchetes angulares). Toda etiqueta empieza con < y termina con >.

Slash barra

The symbol /. It is used in closing tags: </p>. Do not confuse it with the backslash \.

El símbolo /. Se usa en las etiquetas de cierre: </p>. No lo confundas con la barra invertida \.

Comment comentario

A comment is a note for people who read the code. The browser does not show it. Comments start with <!-- and end with -->.

Un comentario es una nota para las personas que leen el código. El navegador no lo muestra. Los comentarios empiezan con <!-- y terminan con -->.

Browser navegador

The program you use to open web pages: Chrome, Firefox, Safari, Edge. The browser reads the HTML and shows the page.

El programa que usas para abrir páginas web: Chrome, Firefox, Safari, Edge. El navegador lee el HTML y muestra la página.

Indentation sangría

Spaces at the start of a line of code. The browser ignores them. We use them so people can see which elements are inside other elements.

Los espacios al principio de una línea de código. El navegador los ignora. Los usamos para que las personas vean qué elementos están dentro de otros.

Syntax sintaxis

The rules for writing code correctly. For example: every tag needs < and >, and attribute values go inside quotes.

Las reglas para escribir código correctamente. Por ejemplo: toda etiqueta necesita < y >, y los valores de los atributos van entre comillas.

Careful! Tag vs. label ¡Cuidado! etiqueta

In Spanish, tag and label are both translated as etiqueta. In HTML they are different things. A tag is any <something>. A label is one specific element, <label>, used in forms.

En español, tag y label se traducen igual: etiqueta. En HTML son cosas diferentes. Un tag es cualquier <algo>. Un label es un elemento específico, <label>, que se usa en formularios.

Page structure Estructura de la página

Every HTML page has the same basic structure. <html> holds everything. Inside it, <head> has information about the page (people don't see it on the page). <body> has everything people see.

Toda página HTML tiene la misma estructura básica. <html> contiene todo. Dentro, <head> tiene información sobre la página (la gente no la ve en la página). <body> tiene todo lo que la gente ve.

<html> = HyperText Markup Language · Lenguaje de Marcado de Hipertexto

The root element. All other elements go inside it. The lang attribute says the language of the page.

El elemento raíz. Todos los demás elementos van dentro de él. El atributo lang dice el idioma de la página.

<head> = head · cabeza

Information about the page: the title, the character set, links to CSS files. Not shown on the page.

Información sobre la página: el título, el juego de caracteres, enlaces a archivos CSS. No se muestra en la página.

<title> = title · título

The name of the page. You see it in the browser tab, not on the page. It goes inside <head>.

El nombre de la página. Lo ves en la pestaña del navegador, no en la página. Va dentro de <head>.

<body> = body · cuerpo

Everything people see on the page goes here: text, images, links, lists, tables, forms.

Todo lo que la gente ve en la página va aquí: texto, imágenes, enlaces, listas, tablas, formularios.

Text elements Elementos de texto

<h1> to <h6> h = heading · encabezado / título

Headings are titles. <h1> is the biggest and most important. <h6> is the smallest. Use only one <h1> per page.

Los encabezados son títulos. <h1> es el más grande y el más importante. <h6> es el más pequeño. Usa solo un <h1> por página.

<p> p = paragraph · párrafo

A paragraph of text. The browser adds space above and below each paragraph.

Un párrafo de texto. El navegador agrega espacio arriba y abajo de cada párrafo.

<br> br = break (line break) · salto de línea

Starts a new line inside text. It is an empty element: no content, no closing tag.

Empieza una nueva línea dentro del texto. Es un elemento vacío: sin contenido y sin etiqueta de cierre.

<strong> and <em> em = emphasis · énfasis; strong · fuerte

<strong> marks very important text. It is usually bold. <em> marks text you say with emphasis. It is usually italic.

<strong> marca texto muy importante. Normalmente se ve en negrita. <em> marca texto que se dice con énfasis. Normalmente se ve en cursiva.

<div> and <span> div = division · división

Containers. They group other things together. On their own, they don't look like anything. <div> is a big block (it starts on a new line). <span> is small and stays inside a line of text.

Contenedores. Agrupan otras cosas. Solos, no se ven diferentes. <div> es un bloque grande (empieza en una línea nueva). <span> es pequeño y se queda dentro de una línea de texto.

Lists Listas

<ul> ul = unordered list · lista no ordenada

A list with dots (bullets). The order is not important.

Una lista con puntos (viñetas). El orden no es importante.

<ol> ol = ordered list · lista ordenada

A list with numbers. The order is important, like steps in a recipe.

Una lista con números. El orden es importante, como los pasos de una receta.

<li> li = list item · elemento de lista

One item in a list. It always goes inside <ul> or <ol>.

Un elemento de una lista. Siempre va dentro de <ul> o <ol>.

Links and images Enlaces e imágenes

<a> a = anchor · ancla

A link. When you click it, you go to another page. The href attribute says where the link goes.

Un enlace. Cuando haces clic, vas a otra página. El atributo href dice a dónde va el enlace.

<img> img = image · imagen

Shows a picture. It is an empty element (no closing tag). src is where the picture is. alt describes the picture for people who cannot see it.

Muestra una imagen. Es un elemento vacío (sin etiqueta de cierre). src es dónde está la imagen. alt describe la imagen para las personas que no pueden verla.

Tables Tablas

A table shows information in rows and columns. A row goes left to right. A column goes top to bottom. One box is called a cell.

Una tabla muestra información en filas y columnas. Una fila va de izquierda a derecha. Una columna va de arriba a abajo. Cada cuadro se llama celda.

<table>, <tr>, <th>, <td>

table = table · tabla
tr = table row · fila de tabla
th = table header · encabezado de tabla
td = table data · dato de tabla (celda)

<table> holds the whole table. Each <tr> is one row. Inside a row, <th> is a header cell (bold title) and <td> is a normal cell.

<table> contiene toda la tabla. Cada <tr> es una fila. Dentro de una fila, <th> es una celda de encabezado (título en negrita) y <td> es una celda normal.

Forms Formularios

Forms let people type or choose things and send them. For example: a login page, a search box, or a contact form.

Los formularios permiten a la gente escribir o elegir cosas y enviarlas. Por ejemplo: una página de inicio de sesión, una caja de búsqueda o un formulario de contacto.

<form> = form · formulario

Holds all the parts of a form: labels, inputs, and buttons.

Contiene todas las partes de un formulario: etiquetas, campos y botones.

<label> = label · etiqueta (rótulo)

The text that says what an input is for, like "Name:". Its for attribute must match the input's id. Then clicking the label selects the input.

El texto que dice para qué es un campo, como "Name:". Su atributo for debe ser igual al id del campo. Así, al hacer clic en el label, se selecciona el campo.

<input> = input · entrada / campo

A box where people type. It is an empty element. The type attribute changes what kind of input it is: text, email, password, number, checkbox, and more.

Una caja donde la gente escribe. Es un elemento vacío. El atributo type cambia el tipo de campo: text (texto), email (correo), password (contraseña), number (número), checkbox (casilla) y más.

<button> = button · botón

A button people can click. Inside a form, a button with type="submit" sends the form.

Un botón para hacer clic. Dentro de un formulario, un botón con type="submit" envía el formulario.

<select> and <option> select = select · seleccionar; option · opción

<select> makes a dropdown menu. Each choice in the menu is an <option>. The value attribute is what the form sends. The text is what people see.

<select> crea un menú desplegable. Cada opción del menú es un <option>. El atributo value es lo que envía el formulario. El texto es lo que ve la gente.

<textarea> = text area · área de texto

A big box for long text, like a message. Unlike <input>, it has a closing tag.

Una caja grande para texto largo, como un mensaje. A diferencia de <input>, tiene etiqueta de cierre.
